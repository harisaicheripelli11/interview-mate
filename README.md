# Interview Mate 🤖🎤

An AI-powered mock interview platform built with Flask.

## Features
- AI-based interview questions
- Chat & voice interview modes
- Confidence & clarity scoring
- Performance analytics dashboard

## Tech Stack
- Python (Flask)
- HTML, CSS, JavaScript
- MySQL
- Groq LLM API

## How to Run
```bash
pip install -r requirements.txt
python app.py
